# Licence proposal (NOT a licence; nothing here is asserted)

The author has not chosen or confirmed any licence. Until they do, no rights are granted by this
repository. This file only proposes options.

| Part | Proposal | Notes |
|---|---|---|
| Code (`benchmark/`, `tests/`) | MIT or Apache-2.0 | Apache-2.0 adds an explicit patent grant; MIT is shorter. The code is a new, standalone re-implementation of the scoring; the author must confirm they may release it. |
| Data (`data/`: prompts, readings, human rounds) | CC BY 4.0 | Requires attribution; permits reuse of the answers and prompts. CC0 is the alternative if no attribution is wanted. |
| Images (release archive) | to be decided | The generated images are model output. The author must check the image provider's terms and decide whether to release them under CC BY 4.0, a research-only licence, or not at all. Model output may not be copyrightable in some jurisdictions; this is not legal advice. |
| Judge and reference readings | follows the data licence | Check the model providers' terms for publishing model outputs. |

Open: copyright holder name and year, the account that publishes, and whether the data licence
covers the human rulings as the author's own work.
